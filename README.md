# 特征微生物分析工具（Demo）

输入仪器输出的文字数据（**物种名 + 浓度 + 单位**），本地算出派生指标，与上一条记录对比，
再由 DeepSeek 分两阶段生成「逐物种评价 + 综合报告」，最后导出 Excel。

## 快速开始

```bat
cd D:\dev\microbe-analyzer
.venv\Scripts\python.exe main.py
```

窗口打开时已预填示例数据，直接点 **分析** 即可看到全流程。

## 计算口径

| 指标 | 规则 |
|---|---|
| 物种种类数 | 浓度 > 0 的物种个数 |
| 多样性指数 H' | Shannon，`-Σ(pi·ln pi)`，自然对数，保留 3 位 |
| 均匀度 | `H' / ln(物种数)` |
| 相对丰度 | `浓度 / 总浓度` |
| 优势种群 | 相对丰度 ≥ **3%** |
| 绝对优势种群 | 相对丰度 ≥ **10%** |

阈值在 `app/metrics.py` 顶部，目前写死，后期开修改入口改这两个常量即可。

## 变化分析（方案 A + B）

**来源优先级**：历史库（B）> 文本自带（A）> 无

| 方案 | 说明 |
|---|---|
| **B 历史库** | 每次分析自动存入 `data/history.db`，下次取**同一设备的上一条**做对比。与上一条内容完全相同则不重复存档 |
| **A 文本自带** | 仪器输出里的「较上次变化」字段会被解析出来，历史库没有记录时用它兜底 |

**趋势规则**（阈值照甲方 xlsx 原表）：

| 规则 | 阈值 | 状态 |
|---|---|---|
| 楯纤虫急速变少 | 减少 70%~100% | ✅ 已实现 |
| 钟虫急速变少 | 减少 70%~100% | ✅ 已实现 |
| 轮虫变多 | 增加 > 300% | ✅ 已实现 |
| 游泳纤毛虫占比变多 | 占比增加 > 50% | ⏸ 缺「物种→生态类群」对照表 |
| 固着纤毛虫占比变多 | 占比增加 > 50% | ⏸ 同上 |

规则命中是**确定性判断**，命中后交给 AI 在报告里解释。

## AI 分析：两阶段串联

```
阶段一  逐物种评价  →  JSON：每个物种一条 comment(40~60字) + advice(15~30字)
                     只讲指示意义，不科普"这是什么虫"，会带上「较上次变化」
   ↓   阶段一的全部评价作为阶段二的输入
阶段二  综合报告    →  情况：<150~200字>
                     变化：<120字以内，无变化数据则省略>
                     建议：<每条一行，2~4 条>
```

阶段二的**核心任务**是找出多个物种**共同指向**的问题（如多条评价都提到"溶解氧偏低"），
而不是罗列各物种结论。

## 导出表格（4 个 sheet）

`检测结果`（一行一次检测，物种横向铺开）｜`物种明细`｜
`物种评价`（物种/浓度/相对丰度/较上次变化/综合评价/指导意见）｜`AI分析报告`

## 已知限制（Demo 阶段有意为之）

1. **种群占比没做** —— 缺「物种 → 生态类群」对照表，做不了
2. **时间戳不参与计算** —— 只是手工填写后写进导出表
3. **阈值 3% / 10% 是从单组样本反推的** —— 样本量仅 1，需更多样本验证
4. **趋势规则 4、5 未启用** —— 同上缺对照表
5. **解析器要求物种名是纯中文、且用冒号分隔** —— `内管虫 0.346` 这种空格分隔不支持；
   从 Excel 复制的制表符表格也不支持
6. **多设备** —— 界面上有「设备编号」输入框，但只有单设备场景实测过
