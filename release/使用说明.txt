特征微生物分析工具（Demo）使用说明
================================================================

一、怎么启动
  1. 把整个文件夹解压到一个固定目录（例如 D:\特征微生物分析工具），
     不要放在桌面或临时目录。
  2. 双击「特征微生物分析工具.exe」。
  3. 首次启动会提示"还没有配置 AI"，点右上角「API 设置」，填：
         Base URL : 例如 https://api.deepseek.com
         API Key  : 你的 Key
     然后点「获取可用模型」→ 勾选要用的模型 → 点「保存当前配置」。

二、怎么用
  1. 点左侧「＋ 新建分析」。
  2. 把仪器输出的文本粘进输入框（只写"物种: 浓度"也能识别）。
  3. 建议填一下采样时间（趋势图按它排序）。
  4. 点「分析」，等十几秒。
  5. 右侧有四个页签：
         ① 计算指标   物种数 / 浓度 / 相对丰度 / 优势种群
         ② 物种评价   每个物种的指示意义与工艺建议
         ③ AI 分析报告 整体判断（情况 / 变化 / 建议）
         ④ 趋势对比   多物种折线，可任意开关
  6. 需要表格时点右下角「导出当前记录」。

三、批量导入（画趋势图用）
  点「批量导入」，粘贴多段数据，段与段之间用空行或 --- 隔开。
  · 每段第一行可以写时间（如 2026-10-09 09:00）
  · 不写时间的话，在弹窗里填「起始时间 + 间隔分钟」自动推算

四、数据存在哪里
  exe 同目录下的 data\ 文件夹：
      history.db       历史记录（点左侧列表可回看）
      api_configs.db   API 配置（Key 已用 Windows DPAPI 加密，换台电脑解不开，需重填）
      last_error.txt   AI 调用失败时的请求/响应原文（排查问题时看这个）

五、注意事项
  · 这是 Demo 版，分析结论仅供参考，不能直接用于生产决策。
  · 首次运行 Windows 可能提示"Windows 已保护你的电脑"，
    点「更多信息」→「仍要运行」。
  · 分析时数据会发送给 AI 服务商（如 DeepSeek），如涉及保密数据请先确认。
  · 趋势图请在**同一批连续采样**内使用。不同时期的数据混在同一张图上会被
    连成直线，看起来像"一直平稳"，实际中间可能没测。

六、如果分析显示「本地模拟」
  说明 AI 调用没成功，界面会弹窗说明原因，详细内容见 data\last_error.txt。
  常见原因：
    · API Key 无效或余额不足
    · 中转站/服务商不支持某些参数（程序会自动重试一次）
    · 用的是推理模型，max_tokens 被"思考"用完（把超时或预算调大，或换模型）

七、示例数据
  同目录的「测试数据.txt」里有 9 组数据，每段用 --- 复制开始/结束 --- 包着，
  整段复制粘贴即可。其中：
      · 数据集 1~4：单次分析，分别对应"良好 / 低负荷长泥龄 / 高负荷解体 / 毒性冲击"
      · 数据集 6~8：批量导入，用来画趋势曲线
